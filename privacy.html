Privacy Policy

Last updated: October 23, 2026 · Version française

Auto Shorts (Google Cloud project “VOD-Uploader”) is a personal tool that uploads its owner's own videos to the owner's own YouTube, Instagram and TikTok accounts. It is not offered to the public.

Use of YouTube API Services

This tool uses the YouTube API Services (YouTube Data API v3) to upload videos. By using it, you agree to be bound by the YouTube Terms of Service. Information is handled in accordance with the Google Privacy Policy.

Data accessed and how it is used

With the owner's consent, the tool obtains an OAuth access token limited to the youtube.upload scope. It is used only to upload videos, with their title and description, to the owner's channel. The tool does not read, collect or store any other YouTube data, and accesses no data about other users. Data is never sold, shared, or used for advertising or analytics.

Storage and sharing

The OAuth token is stored only on the owner's computer. It is sent to no server other than Google's. No cookies or tracking are used.

Revoking access and deleting data

Access can be revoked at any time from the Google security settings page. Deleting the tool's files from the computer permanently deletes all stored data, including the token. Any stored data is deleted within 7 days of revocation or on request.

Contact

Questions: open an issue on the project's GitHub page.

Politique de confidentialité

Dernière mise à jour : 23 octobre 2026

Auto Shorts est un outil personnel qui publie les vidéos de son auteur sur ses propres comptes YouTube, Instagram et TikTok. Cette page explique quelles données il utilise et comment.

Données utilisées

Pour publier, l'outil utilise les jetons d'accès fournis par YouTube (Google), Instagram (Meta) et TikTok lorsque l'auteur connecte ses comptes, ainsi que les informations de base de ces comptes (identifiant et nom d'utilisateur) nécessaires à la publication.

Utilisation

Ces données servent uniquement à envoyer les vidéos et leurs légendes sur les comptes de l'auteur. Elles ne sont ni vendues, ni partagées, ni utilisées à des fins publicitaires ou d'analyse.

Stockage

Les jetons sont enregistrés localement sur l'ordinateur de l'auteur et ne sont envoyés à aucun serveur autre que ceux de Google, Meta et TikTok. Aucune donnée n'est collectée sur d'autres utilisateurs.

Utilisation des données Google

L'utilisation et le transfert des informations reçues des API Google respectent les règles relatives aux données utilisateur des services d'API Google, y compris les exigences d'utilisation limitée. L'outil utilise les services d'API YouTube ; voir aussi la politique de confidentialité de Google.

Révocation et suppression

L'accès peut être retiré à tout moment depuis les paramètres de sécurité du compte Google, depuis « Apps et sites web » sur Instagram, ou depuis « Applications connectées » sur TikTok. Supprimer les fichiers de l'outil efface toutes les données qu'il détient.

Contact

Pour toute question, ouvrez une demande sur la page GitHub du projet.
